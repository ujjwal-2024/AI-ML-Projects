# Iris Classification

A Machine Learning and Deep Learning project that classifies Iris flowers into different species based on their measurements.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow/Keras (if used)

## Algorithms
- Perceptron
- Artificial Neural Network (ANN)

## Project Workflow
- Data Exploration
- Data Preprocessing
- Feature Analysis
- Model Training
- Model Evaluation
- Classification Results

## Objective
To classify Iris flower species using traditional Machine Learning and Neural Network approaches.
