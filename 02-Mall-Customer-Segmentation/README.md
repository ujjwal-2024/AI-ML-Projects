# Mall Customer Segmentation

An Unsupervised Machine Learning project that groups mall customers based on their purchasing behaviour and spending patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- K-Means Clustering

## Project Workflow
- Data Exploration
- Exploratory Data Analysis (EDA)
- Feature Selection
- Elbow Method
- K-Means Clustering
- Customer Segmentation Visualization

## Objective
To identify different customer groups and understand their spending behaviour for better business decisions.
