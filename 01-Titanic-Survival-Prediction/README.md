# Titanic Survival Prediction

This project uses Machine Learning to predict whether a passenger survived the Titanic disaster.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Objective
To analyze passenger data and build a classification model to predict survival.

## Algorithm
- Logistic Regression
- Random Forest Classifier

## Dataset
Titanic Dataset
